# MIT Management Courses

This repository converts MIT management and executive education courses into reusable skills, tools, prompts, frameworks, and project applications.

The purpose is not just to take notes, but to operationalize management education into practical business capabilities that can be used by humans and AI assistants.

## Repository Purpose

This repo is parallel to the MSc Data Science / AI repo.

- MSc repo: technical AI, data science, machine learning, and analytics capability
- MIT Management Courses repo: leadership, strategy, organizations, decision-making, execution, and management capability

## Core Principle

Every course must produce:

1. Course understanding
2. Framework summaries
3. Practical assignments
4. Reusable tools
5. AI skill cards
6. Project applications
