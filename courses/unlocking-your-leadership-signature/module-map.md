# Module Map

| Module | Course Theme | Frameworks | Repository Outputs |
|---|---|---|---|
| 1 | Identify leadership signature | Leadership signature, xCards | Signature inventory, role model review |
| 2 | Analyze the past | Family systems model | Past-story map, feedback request |
| 3 | Analyze developed self | Crucibles, 4-CAP+ | Crucible review, 4-CAP+ assessment |
| 4 | Diagnose resistance to change | Immunity to Change | Immunity map, small experiments |
| 5 | First development steps | Authenticity Paradox, Provisional Self | Experiment plan, new behavior tests |
| 6 | Future leadership self | Future-self framework | Final story, milestones, development plan |

## Course Conversion Logic

Each module should be processed in four passes:

1. Concept: What the module teaches.
2. Reflection: What the learner must examine about themselves.
3. Tool: What reusable artifact can be created.
4. Application: How the idea improves real business leadership.
