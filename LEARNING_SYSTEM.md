# Learning System

This repo uses a conversion-based learning system.

The goal is not to summarize courses. The goal is to turn course knowledge into usable capability.

## Course Conversion Pipeline

### Stage 1: Understand

Capture the course promise, audience, modules, frameworks, faculty, and outcomes.

### Stage 2: Decompose

Break the course into modules, frameworks, concepts, assignments, and outputs.

### Stage 3: Operationalize

Convert each framework into a practical tool, checklist, prompt, or workflow.

### Stage 4: Apply

Apply the course to real projects, teams, businesses, decisions, and leadership situations.

### Stage 5: Skillify

Create an AI skill card that allows an assistant to reuse the course capability in future work.

## Required Outputs Per Course

Each course must produce:

1. `course-brief.md`
2. `syllabus.md`
3. `module-map.md`
4. Framework files
5. Assignment files
6. Tool templates
7. Project applications
8. `ai-skill-card.md`
